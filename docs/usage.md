# Usage

```sh
onde --tui
```

This opens the TUI. Plain `onde` prints usage and exits. You can sign up or sign in right there.

| Key | What it does |
|---|---|
| `Tab` | Move between fields |
| `Enter` | Submit or sign out |
| `Ctrl+L` | Go to the sign-in screen |
| `Ctrl+N` | Go to the new account screen |
| `Ctrl+C` | Quit |

## Debug log

Logs are written to `~/.cache/onde/debug.log`.

If you installed through pub.dev, the launcher cache lives under `~/.onde/cli` (see [install.md](install.md)).
